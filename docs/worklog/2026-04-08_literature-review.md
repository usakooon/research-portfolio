# 2026-04-08 既存研究レビュー表

> **Summary (EN):** Built a literature review table of six Space Syntax and accessibility studies (2016–2025): Sharmin & Kamruzzaman, Koohsari et al., Morales et al., Colaço & de Abreu e Silva, Huang et al., and Zhang et al. Each entry records the overview, limitations and expected future research. The shared gap is that these studies rarely combine street-network centrality with elderly users, slope/physical burden and daily-life facilities. This gap is used to position the present study (station areas, elderly people, hilly terrain).
>
> **Phase:** 4. Method revision & conference prep (手法見直し・学会準備) · **Tools/Data:** Literature (Space Syntax, walkability, accessibility)

<td><b>Sharmin &amp; Kamruzzaman (2018)</b><br><i>Meta-analysis of the relationships between space syntax measures and pedestrian movement</i></td>
<td>主要リンク (<a href="https://www.tandfonline.com/doi/abs/10.1080/01441647.2017.1365101">Taylor &amp; Francis Online</a>)</td>
<td>1975–2016年の研究を対象に、Space Syntax 指標と歩行者移動の関係をメタ分析したレビュー。<b>Integration と Choice は歩行移動と正の関係を持ち、とくに angular approach の効果が比較的強い</b>一方、結果の異質性が高いことを示した。 (<a href="https://www.sciencedirect.com/org/science/article/abs/pii/S0144164722001775">ScienceDirect</a>)</td>
<td>研究間の設計差が大きく、<b>都市条件・対象者属性・施設分布・勾配条件</b>の違いを十分に分けて議論できない。つまり「全体傾向」は見えるが、<b>どの都市でなぜ効くか</b>までは弱い。 (<a href="https://www.sciencedirect.com/org/science/article/abs/pii/S0144164722001775">ScienceDirect</a>)</td>
<td><b>高齢者・駅周辺・丘陵地</b>のような特定条件に絞って、Space Syntax 指標の有効性を個別に検証する研究が必要。本研究はこの不足部分を埋めやすい。 (<a href="https://www.sciencedirect.com/org/science/article/abs/pii/S0144164722001775">ScienceDirect</a>)</td>
<td>Axial表現 → 位相的接続性のみ（視覚的・直線的）<br>Segment表現 → メトリック特性とアンギュラー特性を捉える</td>

<td><b>Koohsari et al. (2016)</b><br><i>Walkability and walking for transport: characterizing the built environment using space syntax</i></td>
<td>主要リンク (<a href="https://link.springer.com/article/10.1186/s12966-016-0448-9">Springer</a>)</td>
<td>人口密度と street integration を組み合わせた <b>space syntax walkability (SSW)</b> を提案し、従来の full walkability index と同程度に <b>transport walking frequency</b> と正の関連を持つことを示した。Space Syntax を、歩きやすさそのものではなく、<b>歩行を支える都市構造の代理指標</b>として使った代表例。 (<a href="https://link.springer.com/article/10.1186/s12966-016-0448-9">Springer</a>)</td>
<td>一般成人を対象とした地区スケール分析で、<b>高齢者の身体条件、勾配、階段、施設類型の違い</b>は扱っていない。また、道路単位で「どこが歩きやすいか」を直接評価した研究ではない。 (<a href="https://link.springer.com/article/10.1186/s12966-016-0448-9">Springer</a>)</td>
<td>Space Syntax を<b>駅周辺・高齢者・勾配負荷・生活施設アクセス</b>と結びつけて再解釈する研究が必要。本研究は、その局所版・生活アクセス版として位置づけやすい。 (<a href="https://link.springer.com/article/10.1186/s12966-016-0448-9">Springer</a>)</td>

<td><b>Morales et al. (2019)</b><br><i>Mapping Urban Accessibility in Data Scarce Contexts Using Space Syntax and Location-Based Methods</i></td>
<td>主要リンク (<a href="https://link.springer.com/article/10.1007/s12061-017-9239-1">Springer</a>)</td>
<td>Space Syntax と location-based accessibility を比較し、<b>Space Syntax はネットワーク中心性、location-based methods は施設や土地利用への到達性</b>を主に捉えると整理した。両者は代替ではなく<b>補完関係</b>にあると示した。 (<a href="https://link.springer.com/article/10.1007/s12061-017-9239-1">Springer</a>)</td>
<td>Space Syntax 側の出力は、あくまで<b>ネットワーク内部での中心性解釈</b>に留まりやすく、<b>誰にとって・どの施設へ・どれだけ届きやすいか</b>までは直接分からない。 (<a href="https://link.springer.com/article/10.1007/s12061-017-9239-1">Springer</a>)</td>
<td>Space Syntax と<b>施設分布・利用者属性・時間距離・身体負荷</b>を組み合わせる研究が必要。本研究で考えている「中心道路＋高齢者向け施設分布」は、この橋渡しにかなり近い。 (<a href="https://link.springer.com/article/10.1007/s12061-017-9239-1">Springer</a>)</td>
