# 高齢者の歩きやすさに関する研究
新百合ヶ丘駅・流山おおたかの森駅周辺の比較

## 研究概要
道路ネットワーク上で中心性の高い道は、高齢者にとっても
歩きやすいのでしょうか。

本研究では、地形の異なる2つの駅周辺を対象に、
Space Syntaxによる道路ネットワーク分析、
標高データによる勾配分析、現地調査を組み合わせ、
道路の構造的な中心性と歩行環境の関係を検討しました。

## 研究の問い
道路ネットワークの中心性と地形条件を組み合わせることで、
高齢者の歩行環境をどのように評価できるか。

## 対象地域
- 新百合ヶ丘駅周辺
- 流山おおたかの森駅周辺

## 研究方法
1. 歩行者道路ネットワークの整備
2. Space Syntaxによる道路ネットワーク分析
3. 標高データを用いた勾配分析
4. 中心性と勾配条件の重ね合わせ
5. 現地観察・歩行者数調査・インタビューによる検討

## 主な結果
新百合ヶ丘では、中心性の高い道路にも勾配による負担が
生じる可能性が示されました。
流山おおたかの森では、低勾配の道路が広く分布する傾向が
見られました。

## 限界と今後の課題
調査人数や観測時間には制約があります。
また、標高データだけでは階段や歩行者デッキなどの
立体的な歩行空間を十分に捉えられません。
今後は、歩道幅員や横断環境なども含めた評価が課題です。
