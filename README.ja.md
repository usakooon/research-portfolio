## Introduction（序論）

**背景**：高齢化が進む郊外の駅周辺では、高齢者が日常的に無理なく歩ける道が求められています。従来の歩きやすさ（ウォーカビリティ）の評価は、道路のつながりや目的地への近さが中心でした。そのため、坂や高低差といった高齢者に特有の負担は十分に反映されていません。

**研究ギャップ**：高齢者の歩行速度にもとづく徒歩圏、日本の丘陵地の郊外駅、現地での検証。この3つを組み合わせた研究は限られています。

**研究の問い**：Space Syntaxで道路ネットワーク上の中心と評価される道は、高齢者にとっても歩きやすい道なのか。

**アプローチ**：Space Syntaxによるネットワーク分析と、DEMによる勾配分析を組み合わせました。地形条件と市街地の成り立ちが異なる2駅を比較し、現地観察とヒアリングでGISの結果を検証しました。

## Methods（方法）

| 項目 | 設定 |
|---|---|
| 対象地域 | **新百合ヶ丘**（川崎市麻生区）：丘陵地。北側の土地区画整理から約40年<br>**流山おおたかの森**（流山市）：平坦地。約30 haの駅前の計画市街地 |
| 徒歩圏 | 高齢者の歩行速度 **47 m/分** × 15分 = ネットワーク距離 **705 m** |
| ネットワーク | OSMの歩行者ネットワーク。歩行者デッキ・階段・スロープ・横断歩道・歩道を含み、私道・駐車場・屋内の道は除外。交差点での分割、スナップ、Douglas-Peuckerによる簡略化、ジオメトリの修正を実施 |
| 中心性 | Angular Segment Analysis、解析半径 705 m。**NAIN**（目的地へ向かう動き）と **NACH**（通り抜けの動き）。**平均＋1SD以上**を高中心性とした |
| 勾配 | 10 m以下に分割し、勾配 = \|Z終点 − Z始点\| / 長さ × 100。30%を超える値はNULL。Space Syntaxのセグメント単位に集約 |
| 閾値 | **5%以下**（低勾配）と **8%以下**（許容範囲）。国交省の歩道の勾配基準による |
| 現地調査 | 2026年5月11日（新百合ヶ丘）・18日（流山）。15分間の歩行者カウント、65歳以上へのヒアリング（5段階評価）、Mapillaryによる未撮影区間の撮影 |

詳しい手順：[docs/methodology.md](docs/methodology.md)

## Results（結果）

**勾配**：2駅の徒歩圏の面積と道路延長は同程度（89.4 ha と 94.7 ha、34.2 km と 33.2 km）ですが、勾配の分布は大きく異なります。

| 勾配（道路延長に占める割合） | 新百合ヶ丘 | 流山おおたかの森 |
|---|---|---|
| 5%以下 | 54.2% | 68.6% |
| 5〜8% | 24.5% | 2.7% |
| 8%超 | 21.2% | 2.4% |
| データなし（デッキ等） | 0% | 26.2% |

**中心性**：
- High_NAINの延長は両駅でほぼ同じ（6.28 km と 6.41 km）でした。
- High_NACHは新百合ヶ丘の方がずっと長い（2.28 km と 0.80 km）結果でした。
- 2つの指標の重なり（Jaccard指数）も、新百合ヶ丘の方が大きい（22.8% と 5.7%）結果でした。

**中心性 × 勾配**：閾値を5%から8%に緩めると、新百合ヶ丘ではHigh_NAINの道路が**1.89 km**増えました。流山では**0.15 km**しか増えませんでした。新百合ヶ丘では、中心的な道の多くが中程度の坂にあります。

| 重ね合わせ | 新百合ヶ丘 | 流山おおたかの森 |
|---|---|---|
| High_NAIN ∩ 5%以下 | 3.36 km（9.8%） | 4.02 km（12.1%） |
| High_NAIN ∩ 8%以下 | 5.25 km（15.4%） | 4.17 km（12.6%） |
| High_NACH ∩ 5%以下 | 1.75 km（5.1%） | 0.61 km（1.8%） |
| High_NACH ∩ 8%以下 | 2.05 km（6.0%） | 0.61 km（1.8%） |

## Discussion（考察）

- **中心的な道が歩きやすいとは限らない。**
  - NAINとNACHは、ネットワーク上での道の位置づけを表す指標です。勾配、歩道の幅、段差、交通量は反映しません。
  - 新百合ヶ丘では、中心的な道、特に通り抜けの道（NACH）に、高齢者の負担になりうる坂が含まれていました。
- **まちづくりの方針がネットワークに表れている。**
  - 流山おおたかの森では、通り抜けは一部の道に集まり、低勾配の目的地へ向かう道は広く分布していました。
  - これは、一方通行化による歩道拡幅や、スラローム状の道路による速度抑制といった、歩行者優先の整備と対応しています。
- **GISの指標だけでは説明しきれない。** 新百合ヶ丘のルートAとBはどちらも平均勾配5%以下の条件を満たしていましたが、感じ方は大きく異なりました。
- **実務での使い方。** 中心性が高い（High_NAINまたはHigh_NACH）のに坂の負担が大きい道を、改善の優先対象として抽出できます。
- **限界。**
  - 対象は2駅だけです。
  - 回答者が少なく、調査した時間帯も限られています。
  - DEMでは、橋・デッキ・階段・立体交差を表せません。
  - OSMの道路種別や歩道の情報の精度にも限界があります。

### 補足（論文には書いていない振り返り）
勾配は10m単位で算出し、Space Syntaxのセグメント単位で平均しました。平均をとると、短い急坂が埋もれる可能性があります。新百合ヶ丘のルートBは、平均勾配4.61%で5%以下の条件を満たしましたが、最も急な部分は11.97%でした。ただし、ルートBの歩きやすさの評価が低かった（2.60）原因を、この急な区間だと言うことはできません。回答者が主に挙げたのは歩道の狭さで、坂は「なだらか」と表現され、「いい運動になる」という声も2件ありました。最大値や95パーセンタイルで集約した場合に分類がどう変わるかの確認は、今後の検証課題です（[判断の記録](docs/decisions.md#4-勾配--slope)）。

## Conclusion（結論）

Space Syntaxと勾配分析を組み合わせることで、道路ネットワーク上で構造的に中心的な道と、高齢者が歩きやすい道とのずれを可視化しました。丘陵地では、ネットワーク上で重要な道が高齢者にとって歩きやすいとは限りません。オープンデータとオープンソースのGISツールだけで構成した手順なので、他の地域の駅周辺にも適用できます。

**今後の課題**
- 対象駅を増やす。
- 歩道幅員、信号、横断歩道、階段、デッキ、土地利用などの要素を加える。
- 3D都市モデルや街路画像を使い、坂・階段・段差を立体的に評価する。
- GeoAIや参加型の評価で、高齢者自身の感覚を取り込む。
